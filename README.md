# Still

Breathe while your AI thinks.

Still is a Mac menu bar app. When Claude or Codex is working and you let go of the mouse for 8 seconds, it turns the wait into a slow breathing break over a live ocean, and steps aside the moment the answer is ready.

**Download:** [Still for Mac](https://github.com/myrondoesnotcode/still/releases/latest/download/Still.dmg) · macOS 13 or later · Apple silicon & Intel · Notarized by Apple

**Website:** https://myrondoesnotcode.github.io/still/

This repository hosts the website and releases.
